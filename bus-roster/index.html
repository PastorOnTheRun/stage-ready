Getting names from WhatsApp

Honest version: WhatsApp doesn't let any website read your chats or contacts, and a free personal account has no export of all your chats or contacts. There is no live sync here. These work instead:

  1. Type or paste from the group. In WhatsApp open the trip group → tap the group name → the participant list. Type names and numbers into Paste a list, one per line: Alex Rivera, 407-555-0100. People not saved in your phone may show a number instead of a name; tap them to see and copy it.
  2. Export the group chat. In the group: group name → Export chat → Without media → save the .txt (or the .zip, then open the .txt inside) to Files. Then Import file here (or paste the text). You get everyone who sent a message (plus anyone shown being added or joining). Expect names only: a chat export usually has no phone numbers at all (saved contacts show your name for them, others show their WhatsApp profile name or, sometimes, their number). Tap Add phone on each person afterward.
  3. Contact cards. Share contacts from your phone (or a WhatsApp contact message) as a .vcf file and import it. Name and number both come through.
  4. CSV from a sign-up list. If the trip sign-up sheet has names and phones, export it as CSV and import it. Columns named Name / First / Last / Phone / Mobile / Notes / Grade / Campus are picked up.

The WhatsApp button on each person just opens wa.me/<number>, which starts a chat with that number in WhatsApp. Numbers without a country code are treated as US (+1); change that in Settings.
